# Сарксис

Мрачный автобаттлер для телефона на Godot: три колонии паразитов, боги-игроки
и сетевая партия до 8 игроков.

- **Сайт:** https://dranichme.github.io/sarkis/
- **Играть в браузере:** https://dranichme.github.io/sarkis/play/

`index.html` и `assets/` — страница игры; `play/` — сборка Godot для браузера
(Web, без потоков — работает на обычном хостинге, в том числе GitHub Pages).
